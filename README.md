# Syntria Backend

Syntria is an AI-powered community initiative execution platform that helps municipalities, community organizations, resource partners, and citizens collaborate to solve community challenges efficiently.

This repository contains the **Node.js/Express.js backend API** built with the **MERN stack**, using **MongoDB** and **Mongoose** for data persistence. The backend provides secure RESTful APIs for managing community issues, initiatives, resources, volunteers, and execution workflows.

## Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication
* Role-Based Access Control (RBAC)
* REST API
* Postman API Testing

## Core Features

* AI-assisted community issue reporting
* Duplicate issue detection and community support
* Municipality review and initiative conversion
* Initiative creation and approval workflow
* Dynamic resource marketplace
* Resource reservation and double-booking prevention
* Initiative phases, tasks, and dependency management
* Volunteer coordination and assignments
* Initiative readiness evaluation
* Execution tracking and municipality verification
* Notification system
* Public impact portal
* Secure authentication and authorization

## User Roles

* Community Member
* Municipality
* Community Organization
* Resource Partner

## Architecture

The backend follows a layered architecture consisting of:

* Routes
* Controllers
* Services
* Middleware
* Mongoose Models
* Validation Layer
* MongoDB Database

## API Testing

All endpoints are designed to be tested using **Postman**, with JWT-based authentication for protected routes.
